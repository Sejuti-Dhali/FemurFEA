# FemurFEA — Femoral Geometry Structural Analysis

Interactive educational case study based on KUET Biomedical Engineering simulation laboratory report, Experiment 03, Problem 3.1 (merged PDF pages 52–56 and 63). Original ANSYS Student plots dated January 31, 2024 are reproduced as cropped report figures. Credit belongs to the original report contributors; confirm permission before public redistribution.

## Method
Static structural analysis, fixed support, 5 mm mesh element size, 550 N and 1050 N forces, structural steel and Ti-6Al-4V assigned to femur geometry. These are metallic material assignments, not a physiological bone model.

## Run
Open index.html in a browser or publish repository root with GitHub Pages. No dependencies.

## Limitations
No new FEA, solver files, mesh convergence study or clinical validation. Values transcribed from PDF page 63. Figure 3.5 caption says 0.00025026 m while its legend and table say 0.00024324 m; the table value is used. Other small rounding differences are retained. Contours have separate color scales. The interactive controls select existing results, not solve new cases. Original full report is not redistributed.
